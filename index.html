ZETA Pro

A modern, modular UI library for Roblox executors, written in Luau. Dark by default, themeable at runtime, and built to clean up after itself.

Quick start

  1. Install

    Run this in your executor. ZetaPro loads itself, and running it again replaces the previous instance.

    local Zeta = loadstring(game:HttpGet("https://raw.githubusercontent.com/realkalii/ZetaPro/main/src/init.luau"))()
  2. Create your first window

    Copy the full script below. It builds the same window as the playground above.

    local Zeta = loadstring(game:HttpGet("https://raw.githubusercontent.com/realkalii/ZetaPro/main/src/init.luau"))()

local Window = Zeta:CreateWindow({
    Title = "ZETA Pro",
    SubTitle = "Quick start",
    Theme = "Zeta",
    MinimizeKey = Enum.KeyCode.RightControl,
})

local Main = Window:AddTab({ Title = "Main", Icon = "home" })
local Section = Main:AddSection("Basics")

Section:AddButton({
    Title = "Say hello",
    Description = "Shows a notification",
    Callback = function()
        Zeta:Notify({ Title = "ZETA Pro", Content = "Hello!", Type = "Success", Duration = 3 })
    end,
})

Section:AddToggle("Enabled", {
    Title = "Enabled",
    Default = true,
    Callback = function(on) print(on) end,
})

Section:AddSlider("Speed", {
    Title = "Speed",
    Min = 16,
    Max = 100,
    Default = 50,
    Callback = function(value) print(value) end,
})

Section:AddDropdown("Mode", {
    Title = "Mode",
    Values = { "Option 1", "Option 2", "Option 3" },
    Default = 1,
    Callback = function(value) print(value) end,
})
  3. Explore

    Press RightControl to hide or show the window, then keep going.

Installation

ZETA Pro is executor-only. One line loads it.

local Zeta = loadstring(game:HttpGet(
    "https://raw.githubusercontent.com/realkalii/ZetaPro/main/src/init.luau"
))()

The loader downloads every module in parallel on first run and caches them for the session. Running the script again unloads the previous instance first, so re-executing never stacks windows.

Load from a fork or branch

getgenv().ZETA_BASE = "https://raw.githubusercontent.com/you/ZetaPro/dev/src/"
local Zeta = loadstring(game:HttpGet(getgenv().ZETA_BASE .. "init.luau"))()
GitHub's raw host caches files for a few minutes. After pushing a fix, a quick re-execute can still load the old version.

Quick start

Window, tab, section, components.

local Window = Zeta:CreateWindow({
    Title = "ZETA Pro",
    SubTitle = "Example",
    Size = UDim2.fromOffset(620, 480),
    Theme = "Dark",
    Acrylic = true,
    MinimizeKey = Enum.KeyCode.RightShift,
})

local Main = Window:AddTab({ Title = "Main", Icon = "home" })
local Section = Main:AddSection("Movement")

Section:AddButton({
    Title = "Hello",
    Description = "Prints hello",
    Callback = function() print("Hello from ZETA") end,
})

local Fly = Section:AddToggle("Fly", {
    Title = "Fly",
    Default = false,
    Callback = function(on) print("Fly:", on) end,
})

Fly:SetValue(true)

The optional first argument ("Fly") is a unique id. With an id the component is stored in Window.Options.Fly and its value lives in Zeta.Config. Callbacks run on changes, not at creation.

Window

local Window = Zeta:CreateWindow({
    Title = "ZETA Pro", SubTitle = "V1.0", Icon = "terminal",
    Size = UDim2.fromOffset(620, 480),
    TabWidth = 160,
    MinSize = Vector2.new(420, 320), MaxSize = Vector2.new(1000, 800),
    Theme = "Dark",
    Acrylic = true,
    Blur = true,
    Resize = false,
    CloseButton = false,
    SearchEnabled = true,
    RestoreButton = nil,
    MinimizeKey = Enum.KeyCode.RightShift,
})

Acrylic enables the translucent surface and Blur = false keeps the transparency without the screen blur. Resize shows a resize grip, CloseButton shows an X (OnClose runs, then Destroy), and RestoreButton defaults to true on touch devices.

Window.Options maps ids to components, and Window.OnDestroy is a signal fired before cleanup. The window clamps itself to the screen and can be dragged from the top bar.

Tabs and sections

local Tab = Window:AddTab({ Title = "Main", Icon = "home" })
local Section = Tab:AddSection("Combat")

Tab:SetTitle("Farm"); Tab:SetIcon("zap")
Section:SetTitle("Combat tools"); Section:SetVisible(true)

Tabs and sections accept the same Add* methods: AddButton, AddToggle, AddSlider, AddDropdown, AddMultiDropdown, AddInput, AddKeybind, AddColorpicker, AddParagraph, AddLabel, AddDivider. Layout, scrolling and spacing are automatic. Destroy() removes the tab, its components and their search entries.

Components

Every component shares one API.

comp:GetValue()            comp:SetValue(v)
comp:OnChanged(function(v) end)
comp:SetTitle("..")        comp:SetDescription("..")
comp:SetIcon("check")      comp:SetIcon(nil)
comp:SetTooltip("..")      comp:SetVisible(false)
comp:SetEnabled(false)     comp:Destroy()

Common config: Title, Description, Icon, Tooltip, Visible, Enabled. A wrong type (for example Default = "yes" on a Toggle) raises a clear [ZETA][ERROR].

Button

local B = Tab:AddButton({
    Title = "Execute", Description = "Run it", Icon = "play",
    Callback = function() print("clicked") end,
})
B:Fire(); B:SetCallback(function() end)

Toggle

local T = Tab:AddToggle("AutoFarm", {
    Title = "Auto Farm", Default = false,
    Callback = function(value) print(value) end,
})

Slider

Tab:AddSlider("Speed", {
    Title = "Walk Speed", Min = 16, Max = 250, Default = 16,
    Increment = 1, Rounding = 0,
    Callback = function(v) print(v) end,
})

Drag the bar or type in the value box. Values are clamped, snapped to Increment and rounded.

Dropdown and MultiDropdown

Tab:AddDropdown("Mode", {
    Title = "Mode", Values = { "Legit", "Rage", "Silent" },
    Default = 1,
    Callback = function(v) print(v) end,
})

Tab:AddDropdown("Targets", {
    Title = "Targets", Values = { "Players", "NPCs", "Bosses" },
    Multi = true, Default = { Players = true },
    Callback = function(map) print(map.Players, map.NPCs) end,
})

Default accepts an index or a name. Multi values are always a full map. dropdown:SetValues({...}) replaces the options and drops invalid selections.

Input

Tab:AddInput("Name", {
    Title = "Username", Placeholder = "Username...", MaxLength = 20,
    Numeric = false, Live = false,
    Validate = function(text) return #text >= 3 end,
    Callback = function(v) print(v) end,
})

Commits on focus lost (or every keystroke with Live). Invalid text reverts and the border flashes red.

Keybind

Tab:AddKeybind("Menu", {
    Title = "Toggle UI", Default = Enum.KeyCode.RightShift,
    Callback = function(key) Window:Toggle() end,
    ChangedCallback = function(key) print("rebound", key) end,
})

Click, then press a key or mouse button 2/3. Esc cancels, Backspace clears, right-click resets. Conflicts with another bind show a warning. See Keybinds for the full guide.

Colorpicker

Tab:AddColorpicker("Accent", {
    Title = "Accent", Default = Color3.fromRGB(255, 255, 255),
    Transparency = 0,
    Callback = function(color, transparency) end,
})

Saturation/value square, hue and alpha bars, HEX/RGB/HSV fields, Reset, and Copy HEX when a clipboard exists. Also: GetHex(), SetTransparency(n), GetTransparency().

Paragraph, Label, Divider

Tab:AddParagraph({ Title = "Info", Content = "Some text.", Icon = "info" })
Tab:AddLabel({ Text = "A flat text row" })
Tab:AddDivider({})

Keybinds

Hotkeys that players can rebind at runtime. All keybinds share one input connection and clean up with their component.

Basic example

local Menu = Section:AddKeybind("MenuKey", {
    Title = "Toggle UI",
    Default = Enum.KeyCode.RightControl,
    Callback = function(key)
        Window:Toggle()
    end,
})

Callback runs every time the bound key is pressed and receives the key. Without an id, Section:AddKeybind({ ... }) works too, but only components with an id are saved by Zeta.Config.

Initial key

Default = Enum.KeyCode.RightShift
Default = "RightControl"
Default = Enum.UserInputType.MouseButton2

A string is the name of an Enum.KeyCode and is case-sensitive. An invalid default raises a clear [ZETA][ERROR] when the component is created.

Detect rebinding

Section:AddKeybind("FarmKey", {
    Title = "Farm hotkey",
    Default = "F",
    ChangedCallback = function(key)
        print("Now bound to", key.Name)
    end,
})

Menu:OnChanged(function(key) print(key.Name) end)

ChangedCallback and OnChanged fire when the binding changes, not when the key is pressed. To react to the key press from code, use Menu:OnClick(function(key) end).

Change the key at runtime

Menu:SetValue(Enum.KeyCode.E)
Menu:SetValue("Q")
Menu:Reset()
print(Menu:GetValue().Name)

Players can also click the button and press a new key. Esc cancels, Backspace clears the binding, and right-clicking the button resets it to the default. Binding a key that another keybind already uses shows a warning notification.

Disable or remove

Menu:SetValue(nil)
Menu:SetEnabled(false)
Menu:SetEnabled(true)
Menu:Destroy()
CallEffect
SetValue(nil)Clears the binding. The key shows as None and nothing fires. Also accepts "None".
SetEnabled(false)Keeps the binding but ignores presses and blocks the row until enabled again.
Destroy()Removes the component and its bind. No connections are left behind.

Real example

local Farm = Section:AddToggle("Farm", {
    Title = "Auto Farm",
    Default = false,
})

Section:AddKeybind("FarmKey", {
    Title = "Auto Farm hotkey",
    Description = "Press to turn farming on or off",
    Default = "F",
    Callback = function()
        Farm:SetValue(not Farm:GetValue())
    end,
})

Window key

local Window = Zeta:CreateWindow({
    Title = "My UI",
    MinimizeKey = Enum.KeyCode.RightControl,
})

Window:SetMinimizeKey(Enum.KeyCode.RightShift)
Window:SetMinimizeKey(nil)

The window key must be an Enum.KeyCode; strings are only accepted by the Keybind component. Pass nil to remove it. A floating restore button is available for touch devices.

Good to know

TypingKeybinds do not fire while the game is handling the input, for example when typing in chat or in a text box.
MobileA touch screen has no key to press, so keybinds only fire with a physical keyboard, and a touch cancels rebinding. Use buttons and the restore button on touch devices.
CleanupWindow:Destroy() and Zeta:Unload() remove every bind.

Dialogs

local Dialog = Window:CreateDialog({ Title = "Confirm", Content = "Are you sure?" })
Dialog:AddButton({ Title = "Cancel" })
Dialog:AddButton({
    Title = "Confirm", Primary = true,
    Callback = function() Zeta:Notify({ Title = "Done", Type = "Success" }) end,
})

Any button closes the dialog after its callback. Dialog:Close() closes it from code and Dialog.Closed is a signal.

Notifications

local note = Zeta:Notify({
    Title = "Saved", Content = "Settings saved.",
    Type = "Success",
    Duration = 4,
    Progress = true, Closable = true,
})
note:Close()

They stack at the bottom-right, up to 5 at a time (the oldest closes first), and follow the theme and scale.

Themes

Built in: Dark, Light, Midnight, Zeta.

Zeta:SetTheme("Midnight")
Zeta:GetTheme()  Zeta:GetThemes()

Zeta:RegisterTheme("Crimson", {
    Base = "Dark",
    Background = Color3.fromRGB(13, 9, 10),
    Secondary  = Color3.fromRGB(22, 14, 16),
    Tertiary   = Color3.fromRGB(32, 20, 23),
    Text = Color3.fromRGB(240, 232, 233),
    MutedText = Color3.fromRGB(150, 128, 131),
    Accent = Color3.fromRGB(239, 68, 90),
    AccentText = Color3.new(1, 1, 1),
    Border = Color3.fromRGB(48, 30, 34),
})

Zeta:SetFont(Enum.Font.GothamMedium)
Zeta:SetScale(0.9)

Secondary and Tertiary are aliases of SecondaryBackground and TertiaryBackground, and Base inherits another theme.

Tokens: Background, SecondaryBackground, TertiaryBackground, Text, MutedText, Accent, AccentText, Border, Hover, Pressed, Success, Warning, Error, Info, Overlay and AcrylicTransparency. Missing tokens fall back to the defaults.

Icons

Built-in icons drawn for Roblox script hubs, grouped in families. No assets, no network.

Basic usage

Window:AddTab({ Title = "Main", Icon = "home" })
Section:AddButton({ Title = "Run", Icon = Zeta.Icons.Home })

Plain names such as "home" keep working exactly as before. Zeta.Icons.Home and Zeta.Icons.ChevronDown resolve to the same icons as "home" and "chevron-down".

Families

Add a family prefix with family:name. It is an extension of the same API, so nothing needs to be migrated.

Icon = "lucide:settings"
Icon = "solar:sword"
Icon = "geist:code"
Icon = "craft:monitor"
Icon = "sfsymbols:check"
FamilyBest forExamples
lucideGeneral UI. Accepts every built-in icon name.lucide:settings lucide:home
solarGameplay: combat, movement, weapons, farming, effects.solar:sword solar:axe solar:flame solar:jump solar:rocket
geistCode, scripts, servers, APIs, databases, developer tools.geist:script geist:api geist:server geist:debugger
craftDevices, tools, objects, hardware and media.craft:monitor craft:keyboard craft:camera craft:key
sfsymbolsCompact controls and indicators.sfsymbols:check sfsymbols:toggle sfsymbols:chevron-down

Plain names use the built-in local set. For family:name, the real icons come from Footagesus/Icons. An unknown family or name shows a small fallback dot instead of an error.

Real icons and variants

Each family is downloaded once, in the background, and cached in ZetaPro/icons/. Delete the cached file to refresh it. While a family loads, or if it cannot be loaded, the built-in local icon is shown and then replaced by the real one as soon as it is ready.

Solar names end with a variant: -linear, -outline, -bold, -broken, -line-duotone and -bold-duotone. Not every icon has all of them. solar:bomb picks the first variant that exists, in that order, and solar:bomb-bold-duotone asks for one explicitly.

Custom providers

Zeta:RegisterIconProvider("Mine", function(name)
    if name == "logo" then
        return {
            Type = "Image",
            Source = "rbxassetid://123",
            Tint = true,
        }
    end
    return nil
end)

Zeta:SetIconProvider("Mine")

The active provider receives the full name first, including any prefix. Resolution order:

StepWhat happens
1The active provider is called with the full name, such as "solar:sword".
2If it returned nil and the name looks like family:name, the family resolver runs.
3The built-in set is tried by plain name.
4Nothing found: the fallback dot is shown.

Image icons

Icon = {
    Type = "Image",
    Source = "rbxassetid://123",
    Tint = true,
}

Tint = true paints the image with the theme color. Use Tint = false to keep the original colors, for example for a logo.

Remote icons

Icon = {
    Type = "Url",
    Source = "https://host/icon.png",
    Tint = true,
}

Remote icons are opt-in and never required. They need:

RequirementDetail
HTTPSPlain http links are rejected.
PNGOther formats are rejected.
SizeUp to 256 KB.
Executor supportHttp, FileSystem and getcustomasset.
CacheSaved in ZetaPro/icons/ and reused.
FallbackIf anything fails, the fallback dot is shown and the UI keeps working.

Plain names such as "home" are local and never use HTTP. Family icons download one file per family, not one request per icon, and fall back to the local set if that fails.

Hot swap

Tab:SetIcon("x")
Component:SetIcon("check")
Component:SetIcon("solar:flame")
Component:SetIcon(nil)

The icon element is updated in place. The tab or component is not rebuilt, and nil removes the icon.

Compatibility

Icon = "home" is still valid and always will be. Icon = "solar:sword" is only an extension of the same API: existing scripts do not need to change.

Config and state

Components with an id store their value in Zeta.Config, so settings can be exported, imported and saved.

Zeta.Config:Set("Speed", 60)
Zeta.Config:Get("Speed")
local data = Zeta.Config:Export()
Zeta.Config:Import(data)
Zeta.Config:Reset()

local ok, err = Zeta.Config:Save("default")
local ok2, err2 = Zeta.Config:Load("default")

Save and Load need file system support and return false, reason otherwise. Supported values: boolean, number, string, Color3, Enum items and tables.

Troubleshooting

The UI does not load

Errors start with [ZETA][ERROR] and name the failing module. Check that your executor supports game:HttpGet and loadstring. Enable Zeta:SetDebug(true) for tracebacks.

Loading is slow on mobile

The first run downloads about 40 small files. Execution after that reuses the session cache. Slow networks or a throttled raw host make the first run longer.

My fix is not showing up

raw.githubusercontent.com caches for a few minutes. Wait, or load from a commit URL through ZETA_BASE.

Save and Load return false

The executor has no file system access. Check Zeta.Capabilities.FileSystem.

Cleaning up

Window:Destroy() removes one window. Zeta:Unload() removes everything, including notifications and keybinds.

FAQ

Quick answers to common questions.

What is ZetaPro?

A modern UI library for Roblox executors, written in Luau. It gives you windows, tabs, sections, buttons, toggles, sliders, dropdowns, inputs, keybinds, color pickers, dialogs and notifications, with themes, icons, config saving and full cleanup built in.

How do I install ZetaPro?

Run one line in your executor:

local Zeta = loadstring(game:HttpGet("https://raw.githubusercontent.com/realkalii/ZetaPro/main/src/init.luau"))()

See Installation and the Quick start.

Does ZetaPro support themes?

Yes. Dark, Light, Midnight and Zeta are built in, you can register your own with Zeta:RegisterTheme, and Zeta:SetTheme updates the whole UI instantly. See Themes.

How do icons work?

Use a plain name like "home", or a family name like "solar:sword" or "geist:code". You can also use your own image or a custom provider. See Icons.

Can I create custom components?

Yes. Zeta:RegisterComponent(name, factory) adds a new Add<Name> method to tabs and sections. See Custom components.

Does it work on mobile?

Yes. Dragging, scrolling and tapping work with touch, the sidebar becomes compact on small windows, and a floating restore button brings the window back. Keybinds need a physical keyboard. See Keybinds.

How do I report a bug?

Open an issue on GitHub and include the full error text (library errors start with [ZETA][ERROR]), your executor name, the smallest script that shows the problem, and what you expected to happen. A screenshot helps for visual bugs.

Where can I get support?

Join the Discord server to ask questions, get help with your scripts and share what you build.
